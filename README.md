# ev-charging-demand-infrastructure-analytics

## 📌 Project Overview
With the rapid growth of electric vehicles (EVs), efficient charging infrastructure has become essential. This project analyzes EV charging station data to uncover demand patterns, optimize station utilization, and improve revenue using data analytics.

---

## 🎯 Objectives
- Identify peak EV charging hours  
- Analyze station utilization  
- Detect high-demand locations  
- Forecast charging demand  
- Optimize revenue and profit  
- Provide infrastructure recommendations  

---

## 🛠️ Tech Stack
- Python (Pandas, Matplotlib, Seaborn)  
- SQL (MySQL / SQL Server)  
- Power BI  
- Excel (Optional)  

---

## 📊 Dataset Summary
Total Records: **4509**

### Features:
- Station ID  
- City  
- Date  
- Charging Start & End Time  
- Energy Consumed (kWh)  
- Cost (INR)  
- Payment Method

## 💡 Key Insights
- Peak demand: **6 PM – 9 PM** ⚡  
- Highest revenue cities: **Pune & Delhi**  
- Top utilized stations: **ST004, ST006**  
- ~32% unused capacity in non-peak hours  

---

## 🚀 Business Recommendations
- Install fast chargers in high-demand zones  
- Expand stations in top revenue cities  
- Optimize pricing for off-peak hours  
- Improve infrastructure distribution  

---

## ✅ Conclusion
This project helps identify EV charging demand patterns and provides data-driven strategies to improve efficiency, reduce waiting time, and increase revenue.
